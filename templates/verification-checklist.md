## 门控检查

### 1. 测试

- [ ] 全量单元测试通过（覆盖率 ≥ 85%）
- [ ] 全量集成测试通过
- [ ] E2E 关键流程测试通过
- [ ] QA Director 交叉模型测试通过
- [ ] 无 skipped/flaky 测试（如有，须说明原因）

### 2. 构建

- [ ] 编译零错误
- [ ] 构建产物正常生成
- [ ] 无 deprecation warning（如有，须说明）

### 3. DA 终审

- [ ] 架构简报与实际代码一致
- [ ] 所有架构变更已通过 DA 审查
- [ ] Kill List 所有条目已验证缓解有效
- [ ] 无未处理的 DA 反对意见

### 4. 安全（按需）

- [ ] CSO 安全扫描通过（--strict 模式必跑）
- [ ] 无硬编码密钥/密码/Token
- [ ] CSP/XSS/CSRF 防护到位
- [ ] 敏感数据处理合规
- [ ] 第三方依赖无已知高危漏洞

### 5. 功能验证

- [ ] 核心用户流程手动验证通过
- [ ] 边界条件验证通过（空输入/超长输入/并发）
- [ ] 移动端适配验证通过（如适用）

### 6. 视觉审查（UI Task 专有）

> 仅当项目中存在 `类型 = UI` 的 Task 时触发此 section。所有 UI Task 必须通过 Design Director 审查。

- [ ] 每个 UI Task 有对应的 `.company/design-brief-{TASK_ID}.md`
- [ ] 每个 UI Task 有对应的 `.company/design-review-{TASK_ID}.md`
- [ ] 所有 `design-review` 结论为"通过"
- [ ] Design Director 6 维度审查无未处理问题
- [ ] 设计 Token 与实际 CSS/样式代码一致
