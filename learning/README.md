## 使用方式

1. 每个Phase结束时，CEO会告诉你"现在适合读L-X"
2. 每篇预计30-60分钟（阅读+思考）
3. 每篇最后有深度思考题和动手任务
4. 配合项目中真实的代码和架构理解
5. 术语表随时查阅

## 学习原则

- **先理解WHY，再学HOW**：每个概念先讲它解决什么问题
- **一个概念一个例子**：每个新概念都配套项目中的真实实例
- **不贪多**：一个Phase学1-2篇，消化了再进下一篇
- **动手验证理解**：每篇有一个你可以在项目中完成的mini任务
