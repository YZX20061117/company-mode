# 复盘知识库索引

> 每个项目结束后，复盘文档的关键教训抽取为结构化条目存入此索引。
> 新项目 Phase 0 Pre-Mortem 时检索相关条目，避免重复踩坑。

## 检索方式

新项目启动时，CEO 根据项目特征（技术栈、项目类型、规模）检索以下分类：

```
检索条件示例：
- 技术栈含 "Electron" → 查看所有 tag:electron 的条目
- 项目类型为 "CLI工具" → 查看所有 tag:cli 的条目
- 施工队出过问题 → 查看所有 tag:施工队降级 的条目
```

## 教训条目模板

```markdown
### L-XXX: [一句话总结]

- **日期**：YYYY-MM-DD
- **项目**：[项目名]
- **Phase**：Phase X
- **严重度**：🔴致命 / 🟡重要 / 🟢备忘
- **标签**：`tag1` `tag2` `tag3`

**问题**：[发生了什么]

**根因**：[为什么发生]

**教训**：[一句话原则]

**避免方法**：[在新项目中如何预防]

**相关条目**：L-XXX, L-XXX
```
